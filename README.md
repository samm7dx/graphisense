# GraphiSense

Digital Handwriting Analysis System using Computer Vision and Machine Learning.

## Technologies

- Python
- OpenCV
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter

## Dataset

Potential Dysgraphia Handwriting Dataset of School-Age Children.

The dataset is not included in this repository.

## Disclaimer

GraphiSense is an academic handwriting-analysis and screening-support project. It is not a medical diagnostic system.
